# KolayPazar

Satıcı ve müşteri için tek uygulamada kolay alışveriş.

**Müşteri:** ürünleri gör → sepete ekle → sipariş ver → siparişinin durumunu takip et.
**Satıcı:** ürün ekle/sil, stok takibi, gelen siparişleri Yeni → Hazırlanıyor → Hazır → Teslim edildi şeklinde ilerlet.

## APK nasıl alınır
1. Bu klasörü GitHub'da yeni repoya yükle (branch: `main`).
2. **Actions** sekmesi → *Build APK* çalışır (ya da *Run workflow*).
3. Bittiğinde **Artifacts → KolayPazar-apk** içinden APK'yı indir.

Not: Veriler şu an telefonda yerel saklanır (demo). Gerçek iki telefonlu kullanım için Firebase eklenmeli.
